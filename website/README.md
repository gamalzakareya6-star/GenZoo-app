# GenZoo Website

Arabic RTL landing page for the GenZoo Android app.

## Deploy on Vercel

1. Import the GitHub repository `gamalzakareya6-star/GenZoo-app` into Vercel.
2. Select the branch `website-genzoo-vercel` (or merge the website pull request first).
3. Set **Root Directory** to `website`.
4. Framework Preset: **Other**.
5. Leave Build Command and Output Directory empty; this is a static HTML site.
6. Deploy.

The main download button points to the supplied GenZoo build-125 APK release URL.
