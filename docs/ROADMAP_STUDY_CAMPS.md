# خطة: معسكرات المذاكرة (Study Camps)

مخطط لها للتحديث القادم بعد تحديث تليجرام. لم تُنفَّذ بعد.

## الفكرة
أي مستخدم ينشئ "معسكر مذاكرة" (جروب) عام أو خاص، يستخدم فيه ملفات من قسم المواد أو ملفات من عنده (روابط)،
وينشئ مهام لها deadline، ثم يُحذف المعسكر كاملاً.

## هل هي مجانية؟
نعم على خطة Firebase المجانية (Spark)، بشرط أن الملفات تكون **روابط** (Google Drive) وليست رفعاً على Firebase Storage
(Storage يتطلب خطة Blaze وبطاقة). الإشعارات قبل الـ deadline ممكنة بنفس نظام GitHub Actions + FCM الحالي.

## النسخة الأولى
1. إنشاء معسكر: اسم، وصف، تاريخ بداية ونهاية، عام أو خاص (كود دعوة).
2. الانضمام بالكود + قائمة "معسكراتي" + قائمة المعسكرات العامة.
3. داخل المعسكر: ملفات (من المواد أو رابط) + مهام بـ deadline، والأعضاء يعلّمون "تم" مع شريط تقدم لكل عضو.
4. تنبيه قبل الـ deadline.
5. حذف المعسكر بالكامل (يدوي من المنشئ + تلقائي بعد انتهائه).

## قرارات مقترحة (بانتظار تأكيد المستخدم، افتراضياً كما يلي)
- الحذف التلقائي بعد 3 أيام من تاريخ نهاية المعسكر.
- المنشئ يضيف المهام والملفات، ويعيّن مشرفين يشاركونه الصلاحية.

## الهيكل المقترح في Firestore
- `camps/{campId}`: name, description, isPublic, inviteCode, ownerId, adminIds[], startAt, endAt, deleteAfter
- `camps/{campId}/members/{uid}`: displayName, joinedAt
- `camps/{campId}/tasks/{taskId}`: title, description, deadline, fileRefs[], doneBy[]
- `camps/{campId}/files/{fileId}`: title, url, materialId?
- قواعد: العام مقروء للجميع، الخاص للأعضاء فقط؛ الكتابة للمنشئ/المشرفين؛ الأعضاء يعدّلون "تم" الخاص بهم فقط.
- الحذف: سكربت مجدول (GitHub Actions) يمسح المعسكرات المنتهية وكل ما تحتها.
